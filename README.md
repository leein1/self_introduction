# 자기 소개 사이트
<hr>
블로그를 운영하려다 불편한 부분이 너무 많아 제작하게 된 
SprintBoot(java) + React 프로젝트입니다.

## 1. 제작 동기
<hr>
개발 일지처럼 나의 개발 이력을 남길 방법을 고민했었습니다.

    1. 블로그(tistory, naver, medium 등)
    2. Git pages

정도가 후보였으나, 관리의 불편함과 포스팅의 불편함이 느껴졌습니다.

더불어, 단순 개발 이력/일지 는 의미가 없다는 생각이 들어

    1. 자기소개 / 이력
    2. 프로젝트 단위의 포트폴리오
    3. 각종 테스트
    4. 깃으로 관리 가능한 포스팅

의 기능이 가능하도록 개발중입니다.
